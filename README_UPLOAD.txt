UPLOAD INSTRUCTIONS
1. Extract this ZIP.
2. Upload/overwrite the nine HTML files in the same directory as your current index.html.
3. Upload assets/css/style.css to the existing assets/css/ directory, overwriting the old stylesheet if you intend to use this package's stylesheet.
4. Keep your existing assets/images/, assets/videos/, and other media files. They are not included in this ZIP.
5. After upload, hard-refresh the site (Ctrl+F5).
